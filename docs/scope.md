# Скоуп MVP и список «не делаем»

> Статус: черновик. Заполняется в ONW-5 — на этот документ ссылаются все остальные задачи фазы.

## Ключевые сценарии зрителя

Открыть приложение без регистрации → выбрать город → лента → карточка события →
внешняя ссылка на билет.

## Ключевые сценарии организатора

Логин → создать событие → пройти модерацию → увидеть его в ленте.

## Не делаем в Фазе 0

| Что | Почему не сейчас |
| --- | --- |
| Оплата внутри приложения | Билеты уходят по внешней ссылке; IAP-правила Apple и эквайринг — отдельный проект |
| Отзывы и рейтинги | Нет аудитории, которая их напишет; добавляет второй контур модерации |
| Соцграф и подписки | Не влияет на ключевой сценарий «найти, куда сходить» |
| Рекомендательная лента | Нечего рекомендовать, пока мало событий и нет поведенческих данных |
| Веб-версия | Платформы фазы — iOS и Android |
| Пуш-уведомления | Инфраструктура готовится (ONW-15), сама фича — следующая фаза |

## Критерий выхода фазы

Регистрация → выбор города → создание события с фото и адресом → модерация →
событие в ленте на втором устройстве → жалоба на него и блокировка автора.
