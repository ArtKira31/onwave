# Соответствие App Store Guideline 1.2 (UGC)

> Статус: черновик. Заполняется в ONW-62 — проверяем себя до отправки, а не после реджекта.

- [ ] Премодерация контента обычных пользователей — ONW-31, ONW-32
- [ ] Жалоба на контент с экрана контента — ONW-38, ONW-59
- [ ] Блокировка пользователя с экрана контента и из профиля — ONW-38, ONW-39, ONW-59
- [ ] Реакция модератора на жалобу в течение 24 часов — ONW-32
- [ ] EULA с политикой нулевой терпимости, ссылка в приложении и в метаданных — ONW-61
- [ ] Контактные данные разработчика доступны пользователю
- [ ] Удаление аккаунта из приложения (отдельное требование Apple)
- [ ] Возрастной рейтинг соответствует наличию UGC
- [ ] Демо-аккаунт и заметка для ревьюера: где именно жалоба и блокировка
